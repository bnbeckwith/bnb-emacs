This document walks through the styling used for my [[./Readme.org][Readme]].

* Introduction

The goal of this document is to walk through a stylesheet, documenting
the design decisions, and generating a CSS file along the way in
[[https://en.wikipedia.org/wiki/Literate_programming][Literate Programming]] style.

** Defaults

The first step is to setup some defaults. We'll begin with the font
import. To evoke that nice, classic UNIX feel, I'm going with a
monospace font.

Here's [[https://fonts.google.com/specimen/Sometype+Mono][Sometype Mono]]:
#+begin_src css 
  @import url('https://fonts.googleapis.com/css2?family=Sometype+Mono:ital,wght@0,400..700;1,400..700&display=swap');
#+end_src

Note that for CSS, all =@import= statements must be at the top of the
file. Eventually, if this splits out into multiple files, imports of
those files will need to appear here.

The next step is to setup some =:root= level variables.

** Changing Themes

#+begin_src javascript :tangle "./scriptish.js" :exports code :results silent
  document.addEventListener('keydown', (e) => {
    // Trigger on Shift + T (ignores input fields)
    if (e.key === 'T' && e.shiftKey && !['INPUT', 'TEXTAREA'].includes(e.target.tagName)) {
      const themes = ['rams', 'olivetti', 'mod'];
      const html = document.documentElement;
      const currentTheme = html.getAttribute('data-theme') || 'default';
      
      // Find next theme index and loop around
      const nextIndex = (themes.indexOf(currentTheme) + 1) % themes.length;
      const nextTheme = themes[nextIndex];

      html.setAttribute('data-theme', nextTheme);
      localStorage.setItem('theme', nextTheme); // Persist across reloads
    }
  });

  // Restore saved theme on load
  (function() {
    const savedTheme = localStorage.getItem('theme');
    if (savedTheme) {
      document.documentElement.setAttribute('data-theme', savedTheme);
    }
  })();
#+end_src
